📅 Create an Event

Send a WhatsApp Event directly to the bot in a private message. The bot will announce it in the community group and publish it to the display board.

  1. Open a private chat with the bot
  2. Tap the + attachment icon → select Event
  3. Fill in the title, date, time and description → Send
  4. The bot will reply asking you to confirm the organisers

🖼️ Confirm Organisers & Add Image

An image is required to publish an event. Tap the link the bot sent you — it opens a pre-filled message in WhatsApp. Here's what you'll see and what to do:

  1. Tap the link — WhatsApp opens with a pre-filled message to the bot
  2. Replace @pablo @maria with the real organiser names
  3. Tap 📎 and attach a photo — the event won't publish without one
  4. Tap send — the event goes live instantly

✅ RSVP to an Event

When an event is announced in the group, the bot includes an RSVP link. Tap it to let the organisers know you're coming.

  1. Find the event announcement in the group chat
  2. Tap the RSVP link in the bot's message
  3. It opens a pre-filled message to the bot — just send it

↩️ Cancel your RSVP

Changed your mind? The bot's RSVP confirmation includes a cancel link.

  1. Find the RSVP confirmation the bot sent you
  2. Tap the Cancel RSVP link
  3. Send the pre-filled message — you're removed from the list

👥 See who's coming

As an organiser, the event confirmation includes a link to see the full attendee list.

  1. Find the "Your event is live" message the bot sent you
  2. Tap If you want to see who joined
  3. Send the pre-filled message to get the list

🗑️ Cancel an Event

Only the person who created the event can cancel it. The cancel link is in the event confirmation message the bot sent you.

  1. Find the "Your event is live" message the bot sent you
  2. Tap If you want to delete this event
  3. Send the pre-filled message — the event is removed from the board
